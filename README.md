#  A PyTorch implementation of the CoNNear auditory periphery model and the associated cochlear-domain loss function


## Overview
This repository provides a PyTorch reimplementation of the [CoNNear auditory periphery framework](https://github.com/HearingTechnology/CoNNear_periphery/tree/master), including:

- CoNNear<sub>cochlea</sub>: a convolutional model of cochlear mechanics and frequency selectivity.
- CoNNear<sub>IHC</sub>: an inner-hair-cell stage modeling synaptic transduction and adaptation.
- CoNNear<sub>ANF<sub>L,M,H</sub></sub>: auditory-nerve-fiber models for low-, medium-, and high-spontaneous-rate fibers.

The package is organized around two main interfaces:

- `CoNNearPeriphery`, which composes the full periphery pipeline.
- `CoSDRLoss`, which converts waveforms into cochlear-domain representations and evaluates a training objective based on those representations.


## Using the periphery model
The full pipeline can be instantiated as follows:

```python
import torch
from connear import CoNNearPeriphery

model = CoNNearPeriphery(
    n_cf=201,
    use_ihc=True,
    use_anf=True,
    sum_anf=True,
    load_weights=True,
)
model.eval()

waveform = torch.randn(2, 16384)  # shape: (batch, time) or (batch, 1, time)
with torch.no_grad():
    representation = model(waveform)
```

- `n_cf` controls the number of simulated cochlear channels. Supported values in the current implementation are `201` and `21`.
- `use_ihc` and `use_anf` enable or disable the downstream stages.
- `use_anf=True` requires `use_ihc=True`.
- `sum_anf=True` combines the low-, medium-, and high-spontaneous-rate outputs by weighted summation; otherwise, the three outputs are concatenated along the channel dimension.
- `load_weights=True` loads the pretrained parameters shipped with the repository from the `pth/` directory.
- `pad_context=True` pads the input with context samples to preserve continuity across windowed processing.


### Notes on the model
1. **The current implementation provides 201 and 21 simulated cochlear channels. Other channel counts can be generated by loading the 201-channel cochlear model and removing the undesired filters in the last layer of the cochlear decoder. The simulated cochlear center frequencies are defined in [`config/cf.py`](config/cf.py). They are expressed in kHz and ordered in decreasing frequency, consistent with the original CoNNear model.**

2. **Running the IHC module over 201 cochlear channels may require very large memory allocations, especially for regular-length signals. In practice, this may not be feasible on most GPUs.**

3. **The more efficient [branched variant](https://github.com/HearingTechnology/CoNNear_periphery/blob/branched/), in which a shared ANF encoder feeds three separate ANF decoders, was not implemented in this release, but it could be added in a future version.**


## Using the Co-SDR loss
The cochlear-domain SDR loss can be used as a training objective for waveform enhancement or separation tasks. A minimal example is:

```python
from loss.cosdr import CoSDRLoss

criterion = CoSDRLoss(
    n_cf=201,
    use_ihc=False,
    use_anf=False,
    norm=True,
    scale_invariant=True,
)

loss = criterion(s_estim, s_target, lengths=lengths, orig_sr=16000)
```

### Loss behavior

- The input signals are resampled to 20 kHz internally.
- The auditory representations are computed with the selected CoNNear stages.
- If `lengths` is provided, padded samples are masked so that the loss is computed only over valid signal portions.
- `norm=True` normalizes the representations by their RMS energy prior to computing the objective.
- `scale_invariant=True` applies a projection step analogous to SI-SDR before the computation of the Co-SDR.

 **Compared with the CoSDR formulation described in the original Co-SDR paper (reference to be added later), later experiments showed that the scale-invariant variant is generally more efficient. This option is supported in the current implementation and can be enabled by setting `scale_invariant=True` in the `CoSDRLoss` constructor.**
